Arses Panel - RVG base

این نسخه بر پایه RVG اصلی است و امکانات ساخت کانفیگ و پروتکل‌های آن را نگه می‌دارد.
برند و ظاهر به Arses تغییر داده شده است.

نصب وابستگی‌ها:
  python3 -m pip install -r requirements.txt

اجرا:
  ./start.sh
یا:
  python3 main.py

مهم: فایل main.py و پوشه protocol باید داخل یک پوشه باشند.
